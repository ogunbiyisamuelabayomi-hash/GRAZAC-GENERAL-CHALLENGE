# Number Classification API

A REST API that takes a number and returns interesting mathematical properties about the number, including whether it is prime, perfect, or an Armstrong number, its parity, digit sum, and a mathematical fun fact.

## Project Description

This project was created as part of the Backend Engineering Challenge.

The API accepts a number through a GET request and returns its mathematical properties in JSON format.

It also uses the Numbers API to provide a mathematical fun fact about the requested number.

---

## Features

- Classifies numbers based on their mathematical properties
- Checks if a number is prime
- Checks if a number is perfect
- Checks if a number is an Armstrong number
- Determines whether a number is odd or even
- Calculates the sum of the digits
- Provides a mathematical fun fact
- Returns JSON responses
- Includes CORS support
- Validates user input
- Returns appropriate HTTP status codes
- Publicly accessible after deployment
